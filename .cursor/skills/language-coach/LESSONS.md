# Lessons (language-coach)

Generic principles about **language coaching** mistakes — not the user's vocabulary.

## Depth and disclosure

- **Principle**: Before a long explanation, read `learning/<lang>/TRACKER.md` and the concept file; if depth is `deep`, default to recap + gaps unless the user asks for full re-teach.

## File hygiene

- **Principle**: Grow **Detailed notes** with dated headings; do not erase prior sessions unless correcting a documented error.

## Educational artifacts

- **Make educational code locally self-contained**: For a learner-facing
  snippet or reference function, define non-basic terms and invariants before
  the code, prefer descriptive names over unexplained abbreviations, and list
  exact import syntax beside every function that needs a non-builtin package.
- **Separate topic sources from generated scans**: Keep focused numbered files
  as the editable source of truth and generate the all-in-one cheatsheet from
  an ordered manifest. Verify both section compilation and aggregate drift.
