# Python cheatsheets

- Numbered `NN_<topic>_<structures>.py` files in this folder are the editable source topics.
- `0_cheatsheet.py` is generated from `manifest.json`; do not edit it directly.
- Regenerate with `npm run cheatsheets:generate`.
- Verify with `npm run cheatsheets:verify`.

Each topic file is syntactically valid and carries its direct import requirements locally.
